## 主な技術的知見

1. **`getopt()` はプロセス argv を直接読む** — `$_SERVER['argv']` を書き換えてもモックできない。`parseArguments()` を protected フックとして切り出すことで PHPUnit からテスト可能にした。

2. **`initSQLite.php` はスキーマの第 3 コピーだった** — FT6 F-2 で「2 つある」と記録されていたが、その後 `SchemaCompiler` が整備されたにも関わらず `initSQLite.php` だけ取り残されていた。FT24 で全消去。

3. **`json_encode([])` は `[]`（配列）を返す** — テストで「ボディなし」を模倣する場合は `new \stdClass()` を使う必要がある。`json-only-api.md` に明記。

4. **PHP `DateTimeZone` は "EST" を黙認する** — IANA 識別子の検証は `DateTimeZone::listIdentifiers()` の明示的なメンバシップチェックが必須。`timezone-handling.md` に記載。
